# CODEBASE.md: Repository Map

> One line per folder and file. **Status legend:** ✅ written · ⬜ empty placeholder (to be implemented in the phase shown) · ⏸ deferred (do not start) · 🔒 read-only reference · ⚙️ generated.
> Phases: `D0`–`D7` = [`PLAN_DAEMON.md`](PLAN_DAEMON.md), `S0`–`S6` = [`PLAN_SDK.md`](PLAN_SDK.md).
> Generated per-file daemon docs live in `docs/daemon/<same path>.md`.

## Tech stack at a glance

| Part | Stack |
| :--- | :--- |
| Daemon | C11 · CMake · libuv + llhttp (HTTP server) · libcurl multi + WebSocket (Arkiv RPC) · yyjson · CRoaring · LMDB · libsecp256k1 · tomlc99 · **pgvector 0.8.7 code** (kernels, types, HNSW in-memory graph) · PostgreSQL helper files (list, pairingheap, simplehash, relptr, f2s) |
| Daemon tests | greatest.h (C unit) · libFuzzer · pytest (integration / parity) · schemathesis (contract) · Docker `pgvector/pgvector` (parity oracle) · Python mock-arkiv |
| SDKs | C (libcurl + yyjson) · C++17 (wraps C) · Rust (reqwest/serde/half) · Python ≥ 3.9 (stdlib) · TypeScript/Node ≥ 18 (fetch) |
| Contract | OpenAPI 3.1 · JSON registries · golden files generated by Python |

## Glossary

| Term | Meaning |
| :--- | :--- |
| Arkiv | EVM-based Web3 database. Entities with attributes, TTL in blocks, contract `0x44…44` |
| Entity / key | Arkiv record / its 32-byte id |
| Collection | Arkivector definition (schema tag + writers + column + index) |
| VectorBytes | Arkivector's on-chain vector format (= pgvector in-memory struct with an AV header) |
| as_of_block | Block whose state a response reflects |
| Opclass | pgvector operator class (e.g. `halfvec_cosine_ops`) |
| Segment / arena | Unit of index storage. An arena is pgvector's in-memory HNSW graph area, mmapped |
| pgcompat | Shim layer that lets pgvector code compile without PostgreSQL |
| V/F/S/P | Reuse modes: verbatim / function copy / copy+shim / algorithm port |
| CCR | Contract change request |
| M0–M4 | Cross-track integration milestones |
