# STUBS.md: pgcompat headers and sources

`pgcompat` gives copied pgvector and PostgreSQL code the PostgreSQL API surface it expects, without PostgreSQL.
PostgreSQL files are copied from tag **REL_17_11** (commit `083ac033419f690758508e08c1736089384bbee8`); licence in [`LICENSE.postgresql`](LICENSE.postgresql).

Kinds: **V** verbatim PostgreSQL file · **S** PostgreSQL subset (struct/macros copied, rest dropped) · **stub** Arkivector-owned shim with PostgreSQL names.
